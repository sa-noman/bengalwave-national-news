# Bengal Wave National News

Official development repository for **Bengal Wave**, a mobile-first Bengali digital news platform.

**Status:** Under development. No public website or content management system is live yet.

## Planned technology
- Next.js App Router, React, TypeScript
- PostgreSQL via Supabase (schema and credentials provisioned separately)
- Vercel deployment after build and access review
- Admin-first publishing, with Telegram/Facebook integrations added after approval

## Design direction
Deep forest green and gold branding, an always-visible compact header, a three-column desktop newsroom, thin editorial dividers, a yellow feature/culture section, Bengali typography, a right-side navigation drawer, and a heritage-inspired footer. No LIVE badge or breaking-news ticker.

## Repository workflow
- `main`: stable reviewed changes
- `feature/*`: work-in-progress changes through pull requests
- No passwords, service keys, or personal tokens committed to source control
- No public deployment until separately approved

Read the documentation under `docs/` once the initial foundation is merged.
